# Lei Wei

Personal homepage for [Lei Wei](https://github.com/CAU-LEI), AI Ph.D. researcher at China Agricultural University.

Live site after GitHub Pages is enabled: https://cau-lei.github.io/

## Local preview

```bash
python3 -m http.server 8080
```

Open http://127.0.0.1:8080

## Deploy

This repository is meant to be published as a GitHub user site:

1. Push to `https://github.com/CAU-LEI/CAU-LEI.github.io`
2. Settings → Pages → Deploy from branch `main` / root
3. The site will be available at `https://cau-lei.github.io/`
